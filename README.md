# مرتب إكسل — تنظيف ملفات الإكسل تلقائيًا

موقع + سيرفر خلفي: يرفع المستخدم ملف إكسل فوضوي فينظّفه **داخل متصفحه** (حذف الصفوف
الفاضية والمكررة، الأعمدة الميتة، وتوحيد صيغة التواريخ)، وفيه صندوق «اطلب أي شيء» يرسل
طلب المستخدم بالعربي إلى نموذج ذكاء اصطناعي ويرجّع الرد بشكل JSON (جدول أو نص).

## المكوّنات

| المسار | الوصف |
|---|---|
| `site/index.html` | الموقع كامل (رفع + تنظيف + تحميل + صندوق الطلبات) |
| `site/privacy.html` · `site/terms.html` | سياسة الخصوصية وشروط الاستخدام |
| `app.js` · `server.js` | سيرفر Express فيه `POST /agent` (CORS + تحقق + مهلة + حد طلبات) |
| `lib/prompt.js` · `lib/parse.js` · `lib/providers.js` | بناء الـ prompt، ضمان JSON صالح، مزوّدو AI |
| `README-AR.md` | دليل النشر خطوة بخطوة بالعربي (Render / Railway / Vercel) |

## الـ API

```
POST /agent
{ "columns": [...], "rows": [[...]], "totalRows": 1500, "truncated": true, "query": "طلب المستخدم" }

200 -> { "type": "table", "columns": [...], "rows": [[...]] }
    -> { "type": "text",  "answer": "..." }
خطأ -> { "error": "رسالة واضحة" }
```

## التشغيل محليًا

```bash
npm install
cp .env.example .env      # ثم ضع مفتاح المزوّد في .env
npm start                 # http://localhost:8787/agent
npm run smoke             # ١٠ اختبارات تلقائية
```

## المزوّدون المدعومون

المزوّد الرسمي: **DeepSeek** (`deepseek-chat`) — ويدعم اختياريًا `anthropic` أو `openai`.
لا يوجد أي رد وهمي/تجريبي في الكود؛ كل الردود من النموذج الحقيقي.
المفتاح يُقرأ من متغيرات البيئة فقط — لا يوجد أي مفتاح داخل الكود.

## الأمان

- لا يُرفع ملف المستخدم إلى أي سيرفر؛ التنظيف كله في المتصفح.
- صندوق الطلبات هو الوحيد الذي يرسل بيانات (أسماء الأعمدة + أول ١٥٠ صف + السؤال).
- المفاتيح في متغيرات البيئة، و`.env` مستثنى من المستودع.
